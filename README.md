# 逃离 211 宿舍 · 3D 密室逃脱

期末考试当天早上 7:30，你在电脑前通宵打完最后一把排位后睡着了。醒来发现室友们已经去考场，**门被你自己的自行车锁拴在了门边的桌腿上**，准考证也被藏了起来。8:00 高数开考——找齐线索、打开车锁、带上准考证冲出宿舍！

……然而拉开门，门外没有走廊，只有一整片光。你走进光里——又走进了 211，身后的门"砰"地关上，锁"咔哒"一声又锁上了。**一共四个 211，布局一模一样，画风完全不同**；逃出最后一个，你在美军征兵站门前的候场区里被教官一嗓子喊醒：四个 211 原来全是一场梦，今天是**新兵报到**的日子：

**不限时**：墙上的钟、天色和氧气会随着你待的时间慢慢变化（室友在群里催、宿管阿姨和舱内广播），但永远差一点才到点，不会因为超时失败。

## 怎么玩

- **直接玩**：双击本目录下的 `逃离211宿舍.html`（单文件，已内嵌全部代码和素材，可离线运行；推荐 Chrome / Edge / Safari 最新版）。
- **两种模式**（标题画面选择，会记住上次的选择）：
  - **🎮 游戏模式**：每个房间一把门锁、一串谜题，找齐密码开锁出门。通关一章解锁一章，下次可以从标题画面直接选第二、三、四章开始。
  - **🎬 鉴赏模式**：**没有任务、没有门锁**，四个章节随便选；走到宿舍门口按 E 就穿越到下一关（或者随时按 **N** 立刻穿越），最后一关出门就是结局动画，适合只想看看四个 211 长什么样。房间里的东西照样能玩，只是不再弹线索和密码。
- **开发模式**：
  ```bash
  cd game && npm install && npm run dev
  ```
  然后打开 http://127.0.0.1:5173 。改完代码刷新页面即可（已关闭自动热刷新，避免打断正在进行的游戏）。
- **重新打包单文件**：`cd game && npm run build`，产物在 `game/dist/index.html`（公开版，准考证上是剪影）。
- **换上自己的头像**：把照片存成 `game/src/assets/face.jpg`（这个文件不进仓库），开发模式会自动用上；`npm run build:face` 打包带头像的单文件到 `game/dist-face/index.html`。
- **部署到 Vercel**：在 [vercel.com/new](https://vercel.com/new) 导入这个仓库，设置全部保持默认，直接点 Deploy。根目录的 `vercel.json` 已经配好：在 `game/` 里执行 `npm ci` 和 `npm run build`，发布 `game/dist`（公开版，准考证上是剪影）。之后每次 push 都会自动重新部署。也可以在仓库根目录用命令行部署：`npx vercel --prod`。

## 还原了什么

**场景（来自两段宿舍视频逐帧分析）**：一头是铺满整面墙的灰色落地窗帘；另一头的墙正中间是通往洗手池和厕所的白框玻璃门，门右边挂着一面真的能照出人的穿衣镜；宿舍门在面朝洗手间时右手边那面墙的最里头，门边紧挨着黑色折叠桌。洗手间可以推门走进去：两个脸盆的洗漱台和镜子、带蹲坑和花洒的厕所隔间、黄框防盗窗——窗外的大树上吊着三只猴子。米色 60cm 地砖和地上的裂纹污渍、墙根发黑的白墙、两侧上下铺铁架床 + 白色蚊帐、黄色碎花被子和凉席、粉色 / 灰色床帘、米色书架、老式棕红木书桌和木凳、门边的黑色折叠桌（粉色购物袋、矿泉水）、堆满泡面瓶罐的黑色杂物桌、红白头盔、七层木鞋架、蓝盖收纳箱 + 白色棒球帽、深蓝波点收纳袋、“350” 纸箱、蓝色脏衣篓、深蓝行李箱、挂在床柱上的花纹长卷和蓝色衣架、橙色人字拖、散落一地的复习资料、黄底蓝点袋子、红白大袋子……窗外是对面的宿舍楼。

**主角（来自照片“捏脸”）**：瘦高身材、两侧推短的短碎发、浓眉、笑起来眯成月牙的眼睛和露齿大笑、深靛蓝牛仔夹克（车缝线、胸袋、铜扣、翻领）、黑色牛仔裤、灰白运动鞋；书桌也按照片还原——打游戏的显示器、联想键盘、红扇子鼠标垫、罗技鼠标、白色手机和耳机、苹果、台历、笔记本、蓝色小本子。准考证上贴的是照片里的头像（真人照片没有放进仓库，公开版显示剪影）。

**第二章 · 废弃的 211**：同一间宿舍，只是被遗弃了三十年。所有材质统一“做旧”（去饱和发黄 + 世界坐标噪声算出来的污垢，金属生锈），墙皮剥落露出红砖、霉斑、水渍、碎地砖；窗户被木板钉死，黄昏的阳光从木板缝里斜射进来（体积光柱会随着天色变暗）；灯管掉了一头，屋子中间吊着一个在电线上晃来晃去、会闪的灯泡（它的影子跟着晃），飞蛾绕着它转；天花板漏水，水滴落进积水里荡开涟漪；破窗帘、破蚊帐、蜘蛛网、盖着白布的书桌、倒在地上的凳子、老式 CRT 显示器的雪花屏、墙上刻满的“正”字、一只沿着墙根乱窜的老鼠；洗手间窗外是一棵枯树，树枝上站着一排乌鸦。整章叠一层老胶片滤镜（泛黄、颗粒、划痕、暗角）。

**第三章 · 雨林 211**：还是同一间宿舍，被塞进了热带雨林里一棵大树的树洞底下——写实电影感，和第二章、第四章一个路子。墙是活树的木质内壁（竖向的木纤维、树瘤、渗水的暗痕、墙根的苔藓），天花板是压实的泥土，几条粗大的树根横穿过天花板、顺着墙扎进地板，根上挂着须根、长着层孔菌，常春藤顺着根往上爬；地板是泡过水的旧木地板，墙根积着落叶，天花板的根上往下滴水，地上一小滩积水荡着涟漪。窗外是暴雨里的雨林：远处的树冠剪影、近处被打得东倒西歪的芭蕉叶和龟背竹、三层雨幕，玻璃上挂着水珠、一道道往下淌的水痕；隔一会儿一道闪电，整片林子一层层亮出来，冷白的光从窗口斜着打进屋里（带阴影和光柱），几秒后滚过一声雷。屋里很暗，只有暖色的钨丝灯串、窗边书桌上一盏火苗一跳一跳的煤油马灯、穿衣镜那圈化妆灯泡和电脑屏幕的冷光；所有东西都受了潮（去饱和、发霉），门上是一条缠满藤的生锈铁链和一把老铜锁，北墙上还趴着一只会蹿来蹿去的壁虎。调色暗部偏青绿、亮部偏琥珀，胶片颗粒 + 暗角 + 一层潮湿的薄雾；配乐是雨声里很低的弦乐铺底和几下木琴似的拨弦。室友们变成了一群程序化建模、用两骨骼 IK 驱动的拟人动物（写实的羽毛、短毛和绒毛，湿润的虹膜，眨眼是真的眼皮合上）：
- 🐔 一只白来航、一只红褐色的土鸡戴着 RGB 电竞耳机坐在书桌前**打电脑游戏**（屏幕上的射击游戏是实时画的），啄米似的点头、翅膀狂按键盘、时不时激动得跳起来；拔掉电源它们会跳上凳子狂拍翅膀，鸡毛满天飞。旁边还有一只加油的小黄鸡，可以摸头。
- 🐴 三匹穿条纹棉睡衣的马躺在床上**晚上刷手机**（仰躺、侧躺、趴着踢腿），手机屏幕上的短视频一条条往上滑，看到好笑的会笑得直抖；一开大灯就“啊我的眼睛！”捂着眼睛乱蹬。
- 🐵 一只戴金链子的猴子对着装了一圈化妆灯泡的穿衣镜**不停地照镜子**：秀肌肉、梳头、比枪、嘟嘴飞吻、侧脸、比耶，镜子里是真实反射；洗手间还有一只边刷牙边对镜子抛媚眼。窗外暴雨里的大树上，三只猴子挤在树杈上躲雨打盹，闪电一亮才看得清。

**第四章 · 太空舱 211**：还是同一间宿舍的布局，被搬进了近地轨道——但宿舍的家具**全换成了舱内设备**，每一样都在原来的位置上：四张上下铺变成四台**封闭的休眠舱**（结霜的半透明舱盖、床头状态屏，上层是冷却液罐、压缩机和管线）；书架变成**资料库**（每本书都拿松紧带勒着）；你的书桌和电脑变成**信息接收站**（大屏上实时滚着波形和返回舱发来的消息，顶上一个会转的小锅盖天线）；隔壁书桌变成**生命维持控制台**（O₂ / N₂ 罐、报警灯）；窗前书桌变成**观测台**（望远镜对着舷窗）；鞋架变成**氧气瓶架**，收纳箱变成**补给货箱**，门边杂物桌变成**太空厨房**，门边折叠桌那儿挂着一套**舱外宇航服**；洗手间东半边改成**驾驶舱**（驾驶座、仪表台、返航轨道图、漏水的饮水机），西边的厕所隔间改成**储藏室**，最里头贴墙立着一个贴满警示条的**货柜 G**。整间舱是写实的电影感（参考电影《太空孤航者》）：刷着青绿色漆的铝面板（面板缝、螺丝、检修口、魔术贴、手摸出来的脏印）、米黄色的天花板和灯箱、满墙的线缆、银色波纹通风软管、用绑带勒着的米白色货包、一排排带开关旋钮的设备盒和到处都是的笔记本电脑；夜间模式下舱里很暗，只有两盏暖色的工作灯（其中一盏接触不良）、单色荧光屏的绿光和琥珀光，以及南墙那道开着的舱门——门后的驾驶舱刷着黄褐色的漆，被琥珀色的灯照得发亮；暗部偏青、亮部偏暖的调色，加上胶片颗粒、暗角和一层淡淡的空气感。宿舍门变成带圆形观察窗和转轮的**气闸舱门**，旁边是旧金属密码面板和一盏报警时会转起来扫红光的警示灯。
- **孤身一人**：舱里只剩你和失控的机器人「小圆」。室友们的三台休眠舱都空了——他们 06:52 就坐返回舱回地球了（就像第一章他们先去了考场），只在各自的休眠舱里给你留了言；你自己那台舱盖还开着，里面还在冒冷气，舱壁上贴着室友留的纸条。
- **失重**：主角飘在半空（手臂自然浮在身前、移动时像游泳一样划水），空格上浮、C 下沉，起步和停下都有惯性；满屋的东西都在飘——泡面桶和飘出来的面条、可乐罐、袜子、摊开的书、复习资料、笔、小黄鸭、手柄、枕头、红白头盔、一团转圈的巧克力豆、小水珠——它们被弹簧拉着慢慢自转，人从旁边飘过会被推开，太空碎片擦过时会被震得满屋乱飞。
- **窗外**：一个跟着镜头走的天空盒（在无穷远处，连镜子里的倒影也是对的）——写实的地球（深海到浅海的渐变、森林 / 草原 / 荒漠 / 冰盖、柔软的云团、柔和的晨昏线、海面上的太阳反光、边缘一圈薄薄的蓝色大气、夜里成片的钠灯色城市灯光）、会随太阳变相位的月亮、带一道淡淡横向镜头光的太阳、不闪烁的星星、远处偶尔反一下光的航天器。太空舱每 100 秒绕地球一圈：太阳从身后（满地球）转到地球背后（**日食**——地球变成一个黑色的圆，外面一圈发光的大气，整面都是城市灯光），阳光从北边舷窗斜射进来时屋里会出现光柱和阴影，然后又从驾驶舱的圆窗照进来。
- 天花板附近有个失控的球形助理机器人「小圆」（参照国际空间站上那种会说话的小球：白色磨砂外壳、液晶屏脸——晕乎乎的蚊香眼 / 眨眼 / 笑 / 说话、两侧导风口里的小风扇），一边乱转一边冒火花；驾驶舱里飘着一颗从饮水机漏出来的大水球（菲涅尔反射 + 柔和的高光），里面泡着一张纸条。驾驶舱窗外还会飘过三只穿着宇航服、拴着安全绳冲你挥手的猴子。
- **隐藏任务线 · 书架背后的幽灵**（致敬《星际穿越》）：货柜 G 里约束着一颗微型黑洞「卡冈图雅」（黑色视界、刺眼的光子环、被引力透镜掀到上下两侧的吸积盘光弧、倾斜着旋转的吸积盘）。碰到它之后是一整段两分多钟的过场动画（六十多个镜头，随时可以跳过）：约束失效，整艘船被宇宙一截一截地“吃掉”——切口烧得白热发亮、闪着裂纹，碎片打着转被吸进越长越大的黑洞，南墙、驾驶舱、储藏室一块块没了，外面是星空和大得吓人的卡冈图雅；你拼命飞回主舱，灯闪了几下全灭了，黑暗里，书架上透出一缕光，越来越亮。你抽出那本发光的《高等数学（下）》——书缝后面，是考试前一天夜里 02:47 的 211 宿舍（第一章的写实画风，另外搭在一个场景里、背靠背接在资料库后面）：你和一个室友在打排位，另外两个站在后面指指点点。你对着书缝大喊，他们听不见；你扭头看见身后的飞船正被一点点吞掉，转回来喊得更用力，从书架背后把三本书推了下去。一个室友走过来捡书，凑到书缝跟前——隔着两个背靠背的书架，你们对望了一眼。飞船只剩下书架这一小块的时候，电脑前的那个你停下手，在凳子上转过身，望着书架那道泛着光的缝，笑了一下；镜头从你身后一路退到舱外，最后一小块书架、那道光、还有它身后的卡冈图雅，慢慢被一片白吞没。

**技术**：Three.js（r186）+ Vite。所有模型、贴图（Canvas 程序化绘制）、音效（WebAudio 合成）和动画都是代码生成的，没有任何外部素材文件；实时软阴影、GTAO 环境光遮蔽、Bloom、物体描边高亮、窗帘布料动画、阳光灰尘粒子、紫光手电显形着色器、镜子实时反射（“流畅”画质下自动关闭）、窗外猴子的两段骨骼 IK 动画；拉开窗帘后的丁达尔光柱；每章一套调色（“流畅”画质下用 CSS 滤镜近似）、各章自己的程序化音乐（第二章走调的八音盒、第三章雨声里的低沉弦乐和木琴拨弦、第四章低沉的电影氛围配乐、结局的军乐进行曲）和音效（乌鸦、滴水、电闸火花、咯咯哒、马叫、宿管阿姨的广播、机器人的哔哔声、打呼噜、嘬水、气闸泄压、警报、号角、军鼓、欢呼……）。人物由参数化的 `createCharacter` 生成（肤色、发色、胡子、牛仔夹克 / AGSU 常服），手臂支持两骨骼 IK（敬礼、递帽子、戴帽子）。第四章彩蛋：飞船被吞噬用五个会移动的全局裁剪面围出一个越缩越小的盒子（黑洞、星空、碎片和火花不受影响），切口的白热光边是改了所有内置材质共用的裁剪片段；书架背后的“那天晚上”是另外搭的一整间写实宿舍，绕书架背板转了 180°、放在单独的场景里，每帧用同一个镜头渲染成贴图，按屏幕坐标贴进书缝，所以从任何角度看过去视差都是对的；反过来也一样——镜头架在那天晚上的宿舍里时，主画面直接画那个场景，书架缝后面贴着同一个镜头拍到的太空舱，两边的人能隔着书架互相看见；隔着时空的呼喊是锯齿波 + 元音共振峰合成的。结局广场的天空是 Preetham 大气散射模型，环境反射用同一片天生成。
