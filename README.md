# 逃离 211 宿舍 · 3D 密室逃脱

期末考试当天早上 7:30，你在电脑前通宵打完最后一把排位后睡着了。醒来发现室友们已经去考场，还把你的**准考证、学生证、文具袋**一人藏了一样。8:00 高数开考——冲出门去！

……门一推就开，门外却没有走廊，只有一整片光。你走进光里，白光散开——你是从**洗手间的门**里走出来的，回到的还是这间 211。**像《盗梦空间》里的彭罗斯阶梯一样，门永远推得开，却永远走不出自己的房间**：每一间 211 都有一个任务，只有解开这间屋子里的线索、把任务完成，门外的光才会把你送去下一间。**一共七个 211，布局一模一样，画风完全不同，任务也各不一样**；逃出最后一个，你在美军征兵站门前的候场区里被教官一嗓子喊醒：七个 211 原来全是一场梦，今天是**新兵报到**的日子：

## 怎么玩

- **直接玩**：双击本目录下的 `逃离211宿舍.html`（单文件，已内嵌全部代码和素材，可离线运行；推荐 Chrome / Edge / Safari 最新版）。
- **两种模式**（标题画面选择，会记住上次的选择）：
  - **🎮 游戏模式**：门都没有锁，推开就能出去——但每一间 211 都有一个任务，任务没完成就出门，门外的光只会把你从**洗手间的门**里送回这间屋子（左上角的目标、右上角的格子会告诉你还差什么；绕回来三次有成就「彭罗斯阶梯」）。解开线索、完成任务，出门才去得了下一关。通关一章解锁一章，下次可以从标题画面接着上次的章节玩。
  - **🎬 鉴赏模式**：**没有任务**，从第一章一路逛下去；走到宿舍门口按 E 就穿越到下一关（或者随时按 **N** 立刻穿越），最后一关出门就是结局动画，适合只想看看七个 211 长什么样。房间里的东西照样能玩，只是不再弹线索和密码。
- **更换人物**：标题画面点「更换人物」，用 ‹ › 按钮（或键盘 ← →）左右切换，画面里站着的那个人跟着换，点「就他了」（或 Enter）选好；游戏里在暂停菜单的「人物」一栏也能随时换，新的人就站在原地接着玩，身上戴着的头盔、毛线帽、围巾会跟过去。会记住上次选的人。现在有两个：
  - **bingo**：原来的主角，牛仔夹克（见下面"还原了什么"）。
  - **jigo**：瘦长条、长脸尖下巴、脖子细长；光膀子、光脚、蓝白扎染大裤衩，两只手揣在裤腰里；一咧嘴大笑，头顶就冒出一句 "Hee-Haw!"，还学一声驴叫。
- **开发模式**：
  ```bash
  cd game && npm install && npm run dev
  ```
  然后打开 http://127.0.0.1:5173 。改完代码刷新页面即可（已关闭自动热刷新，避免打断正在进行的游戏）。
- **重新打包单文件**：`cd game && npm run build`，产物在 `game/dist/index.html`（公开版，准考证上是剪影）。
- **换上自己的头像**：把照片存成 `game/src/assets/face.jpg`（这个文件不进仓库），开发模式会自动用上；`npm run build:face` 打包带头像的单文件到 `game/dist-face/index.html`。
- **部署到 Vercel**：在 [vercel.com/new](https://vercel.com/new) 导入这个仓库，设置全部保持默认，直接点 Deploy。根目录的 `vercel.json` 已经配好：在 `game/` 里执行 `npm ci` 和 `npm run build`，发布 `game/dist`（公开版，准考证上是剪影）。之后每次 push 都会自动重新部署。也可以在仓库根目录用命令行部署：`npx vercel --prod`。

结算评分只看用了几次提示（S / A / B / C），另外记录每章用时；成就里有两个是给隐藏任务线的（🕳️ 卡冈图雅、📚 书架背后的幽灵）；每章都在速通线内（第一章 10 分钟、之后每章 5 分钟）能拿到成就「⚡ 闪电侠」。每局各章的数字线索（电台频率、航向、分机号……）、行李箱密码（考试日期）和电脑开机密码都是随机的；结算面板还会记下你一共"绕回原地"了几次，三个室友的名字也每局随机（五条悟、孙悟空、路飞、哪吒……）。

## 还原了什么

**场景（来自两段宿舍视频逐帧分析）**：一头是铺满整面墙的灰色落地窗帘；另一头的墙正中间是通往洗手池和厕所的白框玻璃门，门右边挂着一面真的能照出人的穿衣镜；宿舍门在面朝洗手间时右手边那面墙的最里头，门边紧挨着黑色折叠桌。洗手间可以推门走进去：两个脸盆的洗漱台和镜子、带蹲坑和花洒的厕所隔间、黄框防盗窗——窗外的大树上吊着三只猴子。米色 60cm 地砖和地上的裂纹污渍、墙根发黑的白墙、两侧上下铺铁架床 + 白色蚊帐、黄色碎花被子和凉席、粉色 / 灰色床帘、米色书架、老式棕红木书桌和木凳、门边的黑色折叠桌（粉色购物袋、矿泉水）、堆满泡面瓶罐的黑色杂物桌、红白头盔、七层木鞋架、蓝盖收纳箱 + 白色棒球帽、深蓝波点收纳袋、“350” 纸箱、蓝色脏衣篓、深蓝行李箱、挂在床柱上的花纹长卷和蓝色衣架、橙色人字拖、散落一地的复习资料、黄底蓝点袋子、红白大袋子……窗外是对面的宿舍楼。

**主角（来自照片“捏脸”）**：瘦高身材、两侧推短的短碎发、浓眉、笑起来眯成月牙的眼睛和露齿大笑、深靛蓝牛仔夹克（车缝线、胸袋、铜扣、翻领）、黑色牛仔裤、灰白运动鞋；书桌也按照片还原——打游戏的显示器、联想键盘、红扇子鼠标垫、罗技鼠标、白色手机和耳机、苹果、台历、笔记本、蓝色小本子。准考证上贴的是照片里的头像（真人照片没有放进仓库，公开版显示剪影）。

**可以换的主角 · jigo（来自一张课本上的涂鸦 + 一张宿舍里的照片）**：涂鸦上是一个眯着眼、张大嘴笑的男生，长脸尖下巴、脖子细长，窄肩、长长的直筒身子、细胳膊细腿，腹肌画了三道横线，两只手插在画满星星的大裤衩里，嘴边拉出一根线写着 "Hee-Haw"；照片上是同一个姿势——光着膀子光着脚站在宿舍里，很瘦，腰细、胳膊腿都细，蓝白扎染的大裤衩松松垮垮，两只手揣在裤腰里。游戏里的他不只换了衣服，身材和脸型也照着捏：`createCharacter` 多了 `build`（肩宽、胸腔、腰、胯、胳膊腿粗细、脖子长短粗细）和 `face`（下半张脸收窄、下巴拉长往前翘、颧骨、嘴以下拉长）两组参数——关节位置和胳膊腿的长短不动，所以所有动画、IK、挂在身上的东西都照样能用。和 bingo 比：肩窄一成、腰细将近两成、胳膊腿细两成多、脖子长 2.5 厘米也细一圈；脸窄一些、长一些，下巴尖、往前翘。头发是往一边（他自己的右手边）高高堆起一大蓬、再朝另一边扫过去的分头，两侧推短；头发蓬，戴帽子（头盔、毛线帽、军帽）时帽子自动大一号。笑起来眼睛眯成两道缝、嘴张成一个大 D 字（上排牙和舌头都露出来）；隐约有六块腹肌和两道人鱼线；大裤衩是程序化的扎染（白底上一团团晕开的湖蓝和靛蓝、水洗的浅蓝边、零星溅点）上面撒着几颗深蓝的小星星，松紧裤腰前面垂着两根白抽绳，裤管宽宽地罩到膝盖上面；光腿、光脚（脚后跟、脚背、五个脚趾）。站着和走路时两只手一直揣在裤腰里（手臂用两骨骼 IK 把手心钉在裤腰里面，手肘往外撑、手腕往里折），跑起来、蹲下、坐下、伸手拿东西、拿手电、失重、立正敬礼时才抽出来。咧嘴大笑时头顶弹出一个手写的 "Hee-Haw!" 漫画气泡，同时用锯齿波 + 元音共振峰合成一声"嘿——哈——"（吸气时尖、呼气时粗，来两遍）；结局的仪式上他忍住了不笑出声。书架背后"那天晚上"电脑前的那个你，也换成你选的这个人。

**第二章 · 废弃的 211**：同一间宿舍，只是被遗弃了三十年。所有材质统一“做旧”（去饱和发黄 + 世界坐标噪声算出来的污垢，金属生锈），墙皮剥落露出红砖、霉斑、水渍、碎地砖；窗户被木板钉死，黄昏的阳光从木板缝里斜射进来（体积光柱会随着天色变暗）；灯管掉了一头，屋子中间吊着一个在电线上晃来晃去、会闪的灯泡（它的影子跟着晃），飞蛾绕着它转；天花板漏水，水滴落进积水里荡开涟漪；破窗帘、破蚊帐、蜘蛛网、盖着白布的书桌、倒在地上的凳子、老式 CRT 显示器的雪花屏、墙上刻满的“正”字、一只沿着墙根乱窜的老鼠；洗手间窗外是一棵枯树，树枝上站着一排乌鸦。整章叠一层老胶片滤镜（泛黄、颗粒、划痕、暗角）。

**第三章 · 船舱 211**：同一间宿舍，成了一艘跑了三十年的老货轮船头底下的船员舱——凌晨四点，北大西洋，天亮之前。写实电影感，和后面几章一个路子：
- **整间屋子在晃**：船在涌浪里横摇、纵摇（两个周期叠在一起，越往后浪越大，隔一阵还有一个大浪猛地一歪）。屋子本身不动，动的是"重力"：吊在链子上的马灯按阻尼单摆的方程往低的那边摆（灯光跟着走），人也跟着往低的那边歪，镜头跟着歪一点点（人的脑袋会下意识地找水平，但找不全）；地上没过脚背的积水是一整片"永远水平"的水面，屋子一歪它就淌到一边、露出另一边的地板，漂着的拖鞋、塑料瓶和纸船跟着往低处漂；海图桌上的扳手歪到一定角度就开始滑，撞到桌子两头"当"一声。HUD 上的时间旁边是实时的横摇角度。
- **船舱**：铆接钢板舱壁（下绿上白、一道红腰线，漆皮起泡剥落露出红丹底漆，铆钉往下淌锈，墙根一圈盐霜和泡过海水的水渍），红丹漆的花纹钢板地板，奶白漆的甲板底面和横梁、沿墙的管子和电缆桥架、东墙一排船壳肋骨；北墙的大窗户换成了三个铜边舷窗，里面扣着铁盖（蝶形螺母拧死）；门变成一扇水密门（转轮 + 一圈压紧把手 + 一盏状态灯：船还在原地打转时亮橘红，报了新航向变绿）；我的书桌成了电报台（电子管收音机：琥珀色的刻度窗、绿色的调谐"魔眼"、格栅里透出电子管的光；电键、纸带收报机、墙上的摩尔斯电码表），窗边书桌成了海图桌；天花板上一张兜着行李袋和绳子的货网，墙上挂着救生圈、救生衣、铜钟、船钟、气压计、传声筒、灭火器。所有旧东西都过一遍"海风"着色器（去饱和、锈斑霉点、泡过水的那一截发暗发亮）。

**技术**：Three.js（r186）+ Vite。所有模型、贴图（Canvas 程序化绘制）、音效（WebAudio 合成）和动画都是代码生成的，没有任何外部素材文件；实时软阴影、GTAO 环境光遮蔽、Bloom、物体描边高亮、窗帘布料动画、阳光灰尘粒子、紫光手电显形着色器、镜子实时反射（“流畅”画质下自动关闭）、窗外猴子的两段骨骼 IK 动画；拉开窗帘后的丁达尔光柱；每章一套调色（“流畅”画质下用 CSS 滤镜近似）、各章自己的程序化音乐（第二章走调的八音盒、第三章海上的弦乐和手风琴、第四章隧道里的吉他、第五章雨声里的低沉弦乐和木琴拨弦、第六章大提琴、第七章低沉的电影氛围配乐、结局的军乐进行曲）和音效（乌鸦、滴水、电闸火花、咯咯哒、马叫、宿管阿姨的广播、机器人的哔哔声、打呼噜、嘬水、气闸泄压、警报、号角、军鼓、欢呼……）。人物由参数化的 `createCharacter` 生成（肤色、发色、胡子、脸型、身材、牛仔夹克 / AGSU 常服 / 扎染大裤衩），手臂支持两骨骼 IK（敬礼、递帽子、戴帽子、手插裤腰）。游戏里换人物时新捏一个人、站到旧的那个人的位置上，挂在关节上的东西（头盔、帽子、围巾）按关节名搬过去（两个人是同一套骨架），旧的那个人的几何体、材质、贴图全部释放。第三章：船的晃动只改"重力"——积水是一整片跟着重力方向转的水平面（被地板的深度遮住的地方自然就"露出"地板），马灯是积分出来的阻尼单摆，人物的朝向在世界坐标里再乘一个倾斜，镜头在渲染前按重力方向重新算一次朝上的方向；海和天都是自己写的着色器，舷窗外的月光是一盏带阴影的平行光（墙和铁盖都投影），所以地上是一个个圆光斑。第四章：盖革计数器按到"热"箱子的距离算泊松分布的咔哒声；站台的灯和从窗户照进屋里的光方向相反，站台上的东西用"自发光"跟着发电机一起调亮，省下一盏点光。第六章：所有材质共用一个"结霜"着色器（世界坐标噪声算出积雪和霜花；暖炉周围热区的半径是一个 uniform，热区一扩大，整间屋子的霜一起化开），窗外的环形城市是几百座实例化的木屋 + 合批的熔炉，隔着半透明冰花的室外不参与 GTAO（不然会把房子"印"在冰花上），窗上的冰花是一张 Canvas，擦的时候直接在上面挖洞；第七章彩蛋：飞船被吞噬用五个会移动的全局裁剪面围出一个越缩越小的盒子（黑洞、星空、碎片和火花不受影响），切口的白热光边是改了所有内置材质共用的裁剪片段；书架背后的“那天晚上”是另外搭的一整间写实宿舍，绕书架背板转了 180°、放在单独的场景里，每帧用同一个镜头渲染成贴图，按屏幕坐标贴进书缝，所以从任何角度看过去视差都是对的；反过来也一样——镜头架在那天晚上的宿舍里时，主画面直接画那个场景，书架缝后面贴着同一个镜头拍到的太空舱，两边的人能隔着书架互相看见；隔着时空的呼喊是锯齿波 + 元音共振峰合成的。结局广场的天空是 Preetham 大气散射模型，环境反射用同一片天生成。
